# A股困境反转与并购重组投资者的每日复盘方法论

> 适用风格：高赔率、一般胜率、低频交易；重点寻找困境反转、资产重组、控制权变更和预期差最大的机会。
>
> 说明：本文是研究与复盘框架，不构成投资建议。重组、退市、财务造假和流动性风险可能导致本金大幅甚至永久损失。

## 一、先定义你的复盘目标

你的复盘不是“找今天涨得最多的股票”，而是每天回答四个问题：

1. **市场正在给什么定价？** 主线、风险偏好、流动性和监管方向是什么？
2. **哪些公司存在非对称赔率？** 下行可估算、上行来自经营修复或事件兑现，且市场可能尚未充分定价。
3. **催化剂离兑现还有多远？** 是传闻、董事会预案、股东大会、监管问询，还是已经进入交割阶段？
4. **我的判断何时会被证伪？** 证伪条件、仓位和退出动作必须在买入前写下。

核心原则：**先判断概率分布，再看价格；先看公告原文，再看媒体解读；先管理失败，再追求成功。**

## 二、每天复盘的固定节奏

### 0. 次日开盘前：只看变化（5—10分钟）

- 扫描隔夜公告、监管动态和公司澄清，确认昨晚结论有没有被新事实推翻。
- 查看候选股集合竞价、停复牌、风险警示和流动性；不因竞价异动临时改变估值模型。
- 写下当天唯一最重要的验证问题，例如“重组问询回复是否披露商誉减值测算”。

### 1. 收盘后第一遍：市场与组合（15—20分钟）

记录以下内容，不做个股冲动决策：

- 指数：上证、深证、创业板、科创50、沪深300的涨跌、成交额、北向/互联互通资金（如有公开数据）。
- 广度：上涨/下跌家数、涨停/跌停、连板高度、炸板率、创阶段新高/新低家数。
- 风格：大盘/小盘、价值/成长、红利/主题、低波/高波谁占优。
- 资金与情绪：两市成交额相对20日均值；融资余额、ETF申赎、可转债成交和高波动题材的资金拥挤度。
- 监管与风险：交易所重点监控、异常波动、减持、退市风险、重大诉讼、ST变化。

输出一段不超过100字的市场结论，例如：

> “指数震荡、成交额低于20日均值，题材集中在并购预期但炸板率上升；风险偏好尚可，适合观察而非追高。”

### 2. 收盘后第二遍：公告雷达（20—30分钟）

对当天重要公告先分层，再阅读原文：

**A类：必须当天读完**

- 重大资产重组、发行股份购买资产、吸收合并、控制权变更、筹划重大事项。
- 业绩预告/快报、年报问询回复、审计意见变化、非标意见消除。
- 债务重组、预重整/重整进展、破产受理、债权人会议、引入战略投资者。
- 退市风险、ST/*ST、暂停上市/终止上市、监管措施。
- 重大合同、核心资产出售或注入、诉讼仲裁、账户冻结、担保违约。

**B类：进入跟踪池**

- 股权转让、国资入股、实控人变化、资产剥离、定增/可转债、回购注销。
- 订单、产能投放、产品涨价、客户认证、海外业务变化。

**C类：只做索引**

- 常规董事会决议、一般关联交易、日常经营合同等。

阅读公告时强制摘录五句话：**发生了什么、对价是什么、时间表是什么、谁承担风险、下一步看什么文件。** 只把可验证事实写入笔记；将“市场传闻/公司表述/自己的推断”分开标注。

### 3. 收盘后第三遍：困境反转扫描（20—30分钟）

用“问题—修复—验证”三栏筛选，而不是凭股价跌幅排序。

**问题是否已反映在价格中？**

- 连续亏损、毛利率下滑、库存和应收异常、产能利用率低、债务集中到期。
- 行业周期底部、产品价格下跌、客户流失、海外制裁或政策冲击。
- 管理层失误、资产减值、商誉风险、审计保留意见、治理缺陷。

**修复是否有现实路径？**

- 行业供需改善或价格回升；成本下降；产能出清；核心客户/产品恢复。
- 剥离亏损资产、引入产业资本、债务展期、现金流改善、治理层更换。
- 经营指标已经先于利润改善：订单、出货、价格、库存周转、现金回款。

**修复是否已被验证？**

- 连续两个以上报告期的关键经营数据改善。
- 现金流而非单纯会计利润改善；减值计提和非经常性收益影响已拆解。
- 估值尚未充分反映正常化盈利，且资产负债表能撑到拐点。

### 4. 收盘后第四遍：并购重组深挖（20—40分钟）

每个候选至少建立一页“重组证据链”：

1. **事件阶段**：传闻 → 停牌/筹划 → 董事会预案 → 股东大会 → 交易所问询 → 注册/核准 → 交割 → 业绩承诺兑现。
2. **交易结构**：发行股份、现金、现金+股份、吸收合并、资产置换、控制权转让、重整投资。
3. **交易对手**：产业资本还是财务投资者；资金来源；是否存在关联关系和一致行动。
4. **标的质量**：盈利真实性、现金流、客户集中度、商誉、估值、业绩承诺可达性。
5. **上市公司代价**：增发摊薄、配套融资、债务、资产注入后的治理和整合难度。
6. **失败路径**：估值过高、问询无法回复、监管否决、股东大会未通过、市场环境变化、承诺无法兑现。
7. **兑现后的估值**：以合并后股本、净利润、净债务计算，不使用“原股价×想象空间”。

重组机会的关键不是“有重组故事”，而是：**事件确定性 × 资产质量 × 价格未反映程度**。

### 5. 睡前复盘：组合与行为（10—15分钟）

逐只持仓回答：

- 今天价格变动是否改变基本面或事件概率？
- 我持有的是事实、逻辑，还是市场情绪？
- 原来的买入逻辑、催化剂和时间窗口是否仍成立？
- 距离止损/止盈/减仓条件还有多远？
- 若今天没有持仓，我会以当前价格买入吗？

最后记录一条行为复盘：今天是否追涨、因噪音交易、忽视公告、过度集中、临时改变规则。

## 三、候选股评分卡

建议每晚只保留10—20只观察股，每只按0—5分打分；总分不代表买入信号，而是决定研究优先级。

| 维度 | 要问的问题 | 评分要点 |
|---|---|---|
| 下行保护 | 最坏情形是什么？净现金、资产价值、清算价值能否支撑？ | 0=无法估算；5=下行可量化且有安全垫 |
| 反转证据 | 修复是否已出现在订单、价格、库存、现金流？ | 0=纯叙事；5=多项连续验证 |
| 重组确定性 | 事件处于哪一阶段？下一份关键文件何时出现？ | 0=传闻；5=接近交割且条件清晰 |
| 资产质量 | 注入资产是否真实、可持续、与上市公司匹配？ | 0=高商誉/高承诺；5=产业协同强、现金流好 |
| 预期差 | 市场共识是什么？哪些事实尚未被价格反映？ | 0=高度拥挤；5=分歧大但证据扎实 |
| 估值赔率 | 正常化市值与当前市值的倍数是多少？ | 0<1.5倍；3=1.5—3倍；5>3倍且可验证 |
| 时间成本 | 兑现可能需要多久？期间是否会持续融资或恶化？ | 0=时间不可控；5=6—18个月内有明确节点 |
| 治理与诚信 | 控股股东、管理层、审计机构历史是否干净？ | 0=重大诚信问题；5=治理改善且可信 |

设定硬门槛：治理/诚信、流动性、退市风险任一为0，原则上不进入实盘候选；赔率不足或缺乏催化剂的股票只保留为研究样本。

## 四、信息源与使用方法

### 一级信源：判断事实

- **巨潮资讯网（CNINFO，www.cninfo.com.cn）**：上市公司公告、定期报告、问询回复、重组报告书、股东大会文件。
- **上海证券交易所（www.sse.com.cn）、深圳证券交易所（www.szse.cn）、北京证券交易所（www.bse.cn）**：监管问询、纪律处分、异常交易、审核进度和上市规则。
- **中国证监会（www.csrc.gov.cn）**：并购重组监管政策、注册/核准、行政处罚、市场禁入。
- **公司官网与投资者关系平台**：公告之外的产品、产能、客户和经营说明；必须与公告交叉验证。
- **国家企业信用信息公示系统（www.gsxt.gov.cn）、中国裁判文书网/执行信息公开网**：股东、实控人、涉诉、执行和失信信息。

### 二级信源：提高效率，不作为最终依据

- Wind、Choice、同花顺、东方财富：财务历史、估值、股东、融资融券、行业数据和公告聚合。
- 行业协会、海关/统计部门、期货交易所、价格信息平台：产量、价格、库存、进出口和开工率。
- 券商研报、媒体、股吧和社交平台：用于发现线索、识别市场共识；涉及重组的关键事实必须回到一级信源。

### 信息核验规则

1. 每个重大结论至少有一个公告或官方数据出处。
2. 时间敏感信息记录“发布日期、文件名称、原文链接”。
3. 将事实、推断、传闻分成三种标签：`F`、`I`、`R`。
4. 对财务数据做三项复核：利润与经营现金流、应收/存货与收入、关联交易与非经常性损益。
5. 传闻只改变研究优先级，不直接改变仓位。

## 五、估值与赔率的最低计算标准

### 困境反转

至少做三种情景：悲观、基准、乐观。对每种情景写明收入、利润率、净利润、净负债和估值倍数，得到对应市值与潜在回报。用概率加权价值判断赔率，但不要把概率精确到小数点后两位制造“虚假精确”。

重点区分：

- 利润恢复是经营性还是减值转回、补贴、资产处置造成的。
- 盈利恢复是否需要大额资本开支和融资。
- “行业回暖”能否传导到公司，而不是只传导到龙头。

### 并购重组

计算合并后口径：

- 新股本 = 原股本 + 发行股份数量；
- 合并净利润 = 上市公司利润 + 标的可持续利润 − 协同成本 − 融资成本；
- 合并净债务、商誉、业绩承诺和潜在减值；
- 以合并后市值/净利润或EV/EBITDA估值，而非只看复牌涨跌幅。

同时给事件概率分档（低/中/高），做“概率×赔率”而不是只看目标价。

## 六、仓位、买卖与风险控制

高赔率策略最怕“小概率永久损失”，建议把风险预算写在前面：

- 单一高不确定性重组标的通常不超过组合净值的5%—10%；确定性明显提高后再逐步增加。
- 单一行业、同一控股股东或同一事件链的总暴露设上限，防止相关性被低估。
- 分批建仓：研究仓、验证仓、兑现仓；每次加仓必须对应新事实，而不是股价上涨。
- 预先写出三类退出：逻辑证伪、事件失败、估值达到目标/赔率消失。
- 对停牌、退市、流动性枯竭、重大处罚等风险设置不可讨价还价的退出或仓位上限。

绝不把以下行为当作风控：摊平所有下跌、用时间换回本、以“公告还没出来”替代证据、用涨停板确认基本面。

## 八、每周与每月的升级复盘

每天解决信息更新，每周解决研究质量，每月解决策略是否有效。

**每周**：复核所有候选的事件阶段、评分变化、关键假设和新证据；删除失去催化剂或赔率的股票；统计“买入理由—实际结果”的偏差。

**每月**：按困境反转、重组、纯主题分别统计胜率、盈亏比、持有期、最大回撤、兑现率和失败原因。重点看期望值，而不是只看胜率：

> 期望值 ≈ 胜率 × 平均盈利 − 败率 × 平均亏损 − 交易成本 − 时间成本

如果连续数月亏损，先检查是否买在事件早期、低估失败概率、忽略治理风险或过度集中，再考虑调整选股模型。

## 九、最终的“下单前一分钟”清单

- 我能用一句话说清市场尚未定价的事实吗？
- 上行来自什么，何时验证，验证失败怎么办？
- 最坏情形是否可能永久损失，而不仅是波动？
- 估值是否按合并后/正常化口径计算？
- 这笔交易是否值得占用未来6—18个月的注意力和资金？
- 如果没有明确答案，动作就是：**不买，继续观察。**
